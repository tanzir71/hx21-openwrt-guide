# Baloo Da 2

Self-hosted variable font, used for Bengali text and the বাংলা language control. English typography and monospace technical values are unchanged.

Source: https://github.com/google/fonts/tree/main/ofl/balooda2

Downloaded 2026-09-02. Weight range: 400–800. Upstream font blob: `2a4e952b1c9d98dd814f22b919f36742df446ce8`.

The original font is unmodified. Its SIL Open Font License is retained in `OFL-BalooDa2.txt`.

The previous Anek Bangla asset and license are retained but are no longer referenced or served by the application.
